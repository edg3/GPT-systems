# Train Qwen-2 0.5B on Godot 4 Documentation
## Goal
Build a Qwen-2 0.5B model that can answer questions about Godot 4 documentation. The model should be able to understand and generate text related to Godot 4, including its features, functions, and best practices.

Datasets are:
- (glaiveai Godot 4 Docs)[https://huggingface.co/datasets/glaiveai/godot_4_docs]
- (minosu Godot 4x 60k)[https://huggingface.co/datasets/minosu/godot_dodo_4x_60k]
- (dotfantasy Godot Code)[https://huggingface.co/datasets/dotfantasy/godot-code]
- **Will add more later, this is just POC V1**
